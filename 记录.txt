文档版本：V1.0

一、游戏定位与核心特色
1.1 游戏定位
一款以“炼金术战斗”为核心的横版格斗网游。玩家扮演使用炼金术的“炼金士”，在分裂的大陆中对抗人造兵器、腐败国家与失控的炼金灾害。核心玩法是刷图、连招、装备构筑与多人副本。

1.2 核心特色
炼成阵战斗系统
所有技能都通过“炼成阵”释放，分为地、水、火、风、金属、生命六大属性。战斗中可组合不同炼成阵，触发元素反应。

等价交换机制
强力技能需要消耗角色生命、魔力、护甲耐久或“炼金素材”。高风险高回报，例如消耗10%当前生命，换取范围爆发。

地形改造与场景破坏
部分技能可改变关卡地形：升起石墙阻挡弹道、将地面变成泥沼、将金属门炼成武器。

连招深度保留
保留 DNF 式浮空、硬直、霸体、破招、背击、扫地连击等动作规则，操作上限高。

炼金工房自由构筑
玩家可以自由装配“炼成式”，类似技能树与符文搭配，形成不同流派。

二、世界观与剧情设定
2.1 背景
在“伊德兰大陆”，炼金术是科学、军事与信仰的顶点。古代炼金术士发现了“阿佐特之石”——一种能够突破等价交换限制的神话物质。围绕这种物质爆发的“炼金战争”将大陆撕成碎片。

战争结束后，所有国家签署《禁石条约》，禁止研究阿佐特之石。但数十年后，各地出现“蚀化现象”：土地金属化、人体与武器融合、死者以半炼金形态复活。玩家扮演“条约执行局”的炼金士，调查背后阴谋。

2.2 主线脉络
第一章：铁锈之城
工业城市居民突然变成半金属怪物，调查发现有人在大规模试验“人造阿佐特之石”。

第二章：苍炎高原
火属性炼成阵失控，天空出现持续燃烧的炼成阵，古代巨龙遗迹被激活。

第三章：生命禁书
有人用炼金术复活亡者，制造出违背伦理的“再生军团”。

终章：神之炼成
反派试图用整座大陆作为炼成阵，将自己炼成“活体真理”。

五、战斗系统详细设计
5.1 操作方式
方向键/摇杆移动，支持上下Y轴移动。

X键：普通攻击（基础炼成武器攻击）

Z键：跳跃

技能键：A/S/D/F/G/H 等可自定义

空格键：闪避/后撤

Q键：切换炼成属性

E键：触发“等价交换”爆发状态

5.2 动作规则
浮空：技能可将敌人击飞，空中可继续连招。

硬直/霸体：敌人被击中会硬直，精英怪和BOSS有霸体条，需破霸体才能控制。

破招：在敌人出招瞬间命中，伤害提高30%。

背击：从背后攻击，伤害提高20%。

扫地连击：对倒地的敌人可继续用特定技能攻击。

5.3 连招评分
采用 DNF 风格的连击评分：

text
D → C → B → A → S → SS → SSS
评分越高，通关结算时额外金币、经验、掉落率越高。

六、炼金术系统
6.1 六元素炼成
所有主动技能属于六种元素之一，元素之间存在反应：

元素组合	反应效果
火 + 水	蒸汽爆炸：范围击退+破甲
火 + 金属	熔金：降低敌人防御，追加灼烧
水 + 地	泥沼：减速与束缚
风 + 火	爆燃：扩大范围，持续伤害
风 + 水	冰冻：短暂冻结敌人
生命 + 金属	寄生金属：持续吸血
地 + 火	熔岩：地面持续伤害
玩家可以在战斗中切换主/副元素，触发“二元炼成”，获得额外效果。

6.2 炼成阵绘制
普通技能为“瞬发炼成”，炼成阵快速出现并消失。

高级技能需要“蓄力炼成”，角色脚下会绘制多层炼成阵，蓄力期间可移动但不可闪避。

玩家可在技能栏中自由组合“基阵 + 元素”，形成自定义技能形态。例如：基阵“投射”+火 = 火球；基阵“爆发”+地 = 地震波。

6.3 等价交换
每个角色有一条“真理值”或“代价槽”。使用特定强力技能会消耗生命、魔力、护甲或“理智”。

代价类型示例：

血之炼成：消耗8%当前生命，技能伤害提高40%。

骨之炼成：消耗10%护甲耐久，获得10秒霸体。

记忆炼成：消耗5%最大魔法值，重置一个基础技能冷却。

禁术炼成：生命低于30%时才可使用，消耗全部魔力，造成巨量伤害。

6.4 贤者之石能量
每个角色拥有“贤者之石碎片”计量槽，通过连击、破招、受击积攒。充满后可主动激活：

10秒内所有技能无代价。

可释放一次“极限炼成”，改变地形并造成全屏伤害。

外观上角色周围出现红色炼成环。

7.1 副本结构
采用 DNF 式房间连接，每个副本5-8个房间，最后为BOSS房。房间类型包括：

普通战斗房

陷阱/解谜房（需要炼成特定元素开门）

宝箱房

BOSS房

7.2 难度分级
普通 / 冒险 / 王者 / 噩梦 / 深渊

难度提升敌人血量、伤害、AI，并新增精英词缀，如“霸体”“火焰光环”“分裂”等。

7.3 炼金环境交互
场景中存在可炼成物：金属板、水源、石墙、油桶等。

玩家使用对应元素可改变环境，例如：

对水源使用火 → 产生蒸汽遮蔽敌人视野。

对金属墙使用电/风 → 磁化吸附敌人。

对地面使用地 → 升起掩体。

《等价之理》Godot 分阶段开发策划案
项目概述
使用 Godot 4.x 开发一款 3D 开放世界动作 RPG，核心玩法围绕“炼金术”与“等价交换”展开。本策划案将项目拆分为多个可独立验证的阶段，从基础移动与战斗开始，逐步扩展至完整的开放世界体验。每个阶段均包含目标、核心系统、Godot 实现要点、验收标准，供团队按序推进。

阶段 0：项目预研与原型验证（1-2 周）
目标
验证核心操作手感与基本战斗循环。

搭建 Godot 项目基础结构。

确定美术风格与性能基准。

核心系统
角色控制器（移动、跳跃、冲刺）

摄像机系统（第三人称跟随）

一个可攻击的敌人与简单 AI

基础攻击连段与闪避

原型场景（平面 + 几个障碍物）

Godot 实现要点
使用 CharacterBody3D 作为角色基类，SpringArm3D + Camera3D 实现跟随。

状态机（AnimationTree 的 StateMachine）管理移动、攻击、闪避状态。

攻击判定使用 Area3D 或 PhysicsShapeQuery 检测命中。

敌人使用 NavigationAgent3D 寻路，简单行为树（追击、攻击、巡逻）。

测试用美术资源：胶囊体角色、方块敌人，验证手感。

验收标准
角色移动流畅，跳跃/冲刺响应及时。

摄像机无穿墙，跟随平滑。

攻击能命中敌人并产生反馈（受击硬直、伤害数字）。

敌人在一定距离内会追击并攻击玩家。

阶段 1：基础战斗与元素属性（3-4 周）
目标
完善战斗系统，引入元素属性与基础反应。

实现角色切换（至少 2 名测试角色）。

加入体力系统与元素战技/爆发。

核心系统
多角色队伍（1 名操控，可切换）

元素类型：地、水、火、风、金、生命（可先实现 2-3 种）

元素附着与简单反应（如 火+水=蒸汽爆炸，火+金=熔金）

元素战技（E）与元素爆发（Q）

体力条影响冲刺、攀爬、重击

敌人元素护盾与破盾机制

Godot 实现要点
角色切换：在场景中保留多个角色实例，隐藏非活动角色，切换时交换位置。

元素系统：使用 Dictionary 存储角色的元素类型，攻击命中时设置目标上的 element_aura（可叠加），当两种元素同时存在时触发反应函数。

技能释放：技能附带冷却、消耗（体力/魔力/生命），可通过 UI 显示。

敌人护盾：敌人有 shield_element 和 shield_health，非克制元素伤害减半，克制元素伤害加倍，破盾后进入易伤状态。

体力：Timer 或逐帧恢复，消耗时禁用相关动作。

验收标准
至少两个角色可切换，拥有不同元素与技能。

元素反应能正确触发并产生视觉效果（颜色变化、爆炸特效）。

体力不足时无法冲刺/攀爬，体力自动恢复。

敌人带元素护盾时，需用克制元素破盾后才可造成有效伤害。

阶段 2：无缝大地图与探索框架（6-8 周）
目标
实现一个可探索的开放世界区域（大小约 1km×1km）。

支持分块流式加载与传送。

加入基础采集、攀爬、滑翔与体力消耗。

核心系统
地形分块（TileMap 或自定义网格），动态加载/卸载

LOD 与遮挡剔除（基础）

采集物（矿石、草药）与资源点

攀爬系统（表面检测 + 体力消耗）

滑翔翼（从高处跳下可展开）

传送锚点与地图

天气/昼夜（可选，先用简单时间循环）

Godot 实现要点
使用 GridMap 或导入的 3D 地形，将其分割为多个 PackedScene，通过 ResourceLoader.load_threaded_request 异步加载。

玩家周围一定距离内加载地块，超出卸载。

攀爬：射线检测可攀爬表面，移动时限制速度，体力耗尽掉落。

滑翔：检测空中状态，玩家按下跳跃键展开滑翔翼，降低下落速度，消耗体力。

采集物：Area3D 检测玩家交互，播放采集动画，获取物品后进入冷却。

传送：放置 Marker3D 作为锚点，解锁后可通过地图 UI 传送。

地图：使用 TextureRect 显示区域平面图，标记玩家位置与已解锁锚点。

验收标准
在区域内移动无明显卡顿（性能目标 60 FPS）。

远离后返回，资源点会重新刷新（简单计时器）。

可以攀爬墙壁、从高处滑翔，体力消耗正常。

解锁传送点后能快速移动。

阶段 3：炼金术核心系统（4-6 周）
目标
实现“等价交换”代价机制。

引入炼成阵与自定义技能组合。

加入炼金合成与背包。

核心系统
代价系统：技能可消耗生命、魔力、体力或特殊素材，提升效果

炼成阵绘制：基阵（投射、范围、召唤等）+ 元素组合

自定义技能槽：玩家可配置 2-3 个主动技能

炼金合成：使用素材制造药水、强化石等

背包与物品数据

Godot 实现要点
代价系统：技能类中包含 cost_type 和 cost_value，释放时检查资源并扣除，同时根据代价提升伤害或范围。

炼成阵：使用自定义 Resource 描述技能（基阵类型、元素、基础数值），角色通过 技能栏 引用这些 Resource。释放时根据组合生成特效（使用 GPUParticles3D 和动态 Shader 绘制炼成阵图案）。

自定义技能：UI 界面让玩家从已解锁的基阵和元素中选择，保存为技能配置。

合成系统：制作配方表（JSON 或 Resource），检查背包材料，扣除后生成物品。

背包：使用 Array[ItemData]，UI 显示格子，支持堆叠、使用、丢弃。

验收标准
释放一个高代价技能会扣除相应资源，并产生明显更强的效果（如范围扩大、伤害提高）。

玩家可以更改技能组合，战斗中能看到不同的炼成阵特效。

能使用采集材料合成药水，药水能恢复生命或提供 Buff。

背包 UI 能正确显示和操作物品。

阶段 4：角色养成与装备系统（4-5 周）
目标
实现角色等级、突破与天赋成长。

加入武器、圣遗物类装备与强化。

核心系统
角色经验与升级（属性成长）

突破材料需求（区域特产、BOSS 掉落）

武器系统（不同类型，可强化）

圣遗物/刻印系统（套装效果）

强化、精炼、附魔

Godot 实现要点
角色数据存储为 Resource，包含等级、经验、基础属性、突破阶段。

突破：消耗特定物品，增加等级上限并提升属性，可能需要完成特定任务。

武器：可装备在角色上，提供基础攻击力和附加属性，可强化（消耗材料提升等级）。

圣遗物：5 个槽位，每个圣遗物有主属性、副属性、套装名，装备 2/4 件触发套装效果。可使用 Dictionary 存储。

强化/精炼：消耗金币与材料，提升装备等级或精炼阶数，有失败率（可设计）。

UI：角色详情面板、背包、装备栏、强化界面。

验收标准
角色升级后属性提升，达到突破条件可突破。

装备武器后攻击力变化，武器可强化。

穿戴圣遗物后触发套装效果（如增加火元素伤害 15%）。

UI 能够查看和更换装备。

阶段 5：任务与剧情框架（3-4 周）
目标
搭建任务系统，支持主线与支线。

实现对话系统与基本剧情演出。

加入世界状态（任务解锁区域或 NPC）。

核心系统
任务数据结构（任务 ID、状态、目标、奖励）

任务追踪与导航

对话系统（分支、选项、NPC 交互）

剧情事件（触发过场动画或特殊脚本）

任务日志 UI

Godot 实现要点
任务使用 Resource 或 JSON 定义，包含多个目标（击杀、收集、到达地点等）。

全局 QuestManager 单例追踪当前任务列表与状态。

对话系统：DialogueBox 节点，使用 RichTextLabel 显示文本，提供选项按钮，根据玩家选择改变 NPC 好感或任务走向。

过场动画：使用 AnimationPlayer 控制摄像机、角色移动，或播放视频（VideoStreamPlayer）。

NPC 交互：Area3D 检测，按交互键打开对话 UI，NPC 状态根据任务进度改变（如头顶感叹号）。

验收标准
完成一个包含 3 个任务的主线链，任务目标能正确更新。

与 NPC 对话有文本显示和选项，选择影响后续对话。

完成任务获得奖励，任务日志更新。

特定任务完成后解锁新区域入口。

阶段 6：多人联机（可选，8-12 周）
目标
实现 2-4 人联机探索与副本。

同步角色状态、敌人 AI 与掉落。

核心系统
网络架构（使用 Godot 的 ENetMultiplayerPeer 或专用服务器）

房间/匹配系统（简单的列表）

同步角色位置、动画、技能释放

敌人 AI 由主机计算，其他客户端表现

掉落物分配与拾取同步

Godot 实现要点
使用 MultiplayerSpawner 和 MultiplayerSynchronizer 同步节点。

主机权限：敌人 AI 和伤害计算在主机执行，客户端发送输入，接收状态。

技能释放同步：使用 RPC 调用，确保所有客户端播放特效。

联机副本：创建独立场景，玩家通过入口进入，房间内怪物血量随人数调整。

网络优化：减少同步频率，使用插值平滑移动。

验收标准
两台设备可加入同一房间，看到对方移动和攻击。

敌人行为在两端一致，伤害计算正确。

掉线重连或主机迁移（可选）。

联机时无明显延迟（<100ms 内可接受）。

阶段 7：内容扩展与打磨（持续迭代）
目标
增加更多区域、角色、BOSS。

加入家园系统、钓鱼、料理等休闲玩法。

引入深渊/高难挑战与活动系统。

性能优化与移动端适配（如需要）。

核心系统
家园炼金工房：可摆放家具、制作特殊物品

钓鱼小游戏

料理系统与 Buff

深渊爬塔（类似深境螺旋）

版本活动框架

Godot 实现要点
家园：使用独立场景，玩家可进入，使用 GridMap 摆放家具，保存布局。

深渊：生成多层战斗房间，每层有不同敌人和 Buff，记录通关时间。

玩家可进入家园并摆放家具，保存后重新进入不丢失。

深渊模式可玩，奖励和难度递增。

性能在目标硬件上保持稳定。

阶段 2：无缝大地图与探索框架
技术选型与关键模块
地形分块：将大地图分割为 64×64 或 128×128 米的 chunk，每个 chunk 保存为独立 PackedScene 或使用 GridMap 动态生成。

流式加载：在玩家周围半径内加载 chunk，使用 ResourceLoader.load_threaded_request() 异步加载，配合 Node3D.add_child() 实例化。

LOD：远处使用低模替换或直接隐藏小物体，利用 VisibilityNotifier3D 和距离判断。

攀爬：射线检测墙面，限制移动方向，体力消耗。

滑翔：空中检测，展开滑翔翼模型，降低重力影响，持续消耗体力。

采集物：Area3D 交互，采集后进入冷却，刷新计时器。

传送点：场景中放置 Marker3D，解锁后保存到全局，地图 UI 传送。

世界地图：捕获区域俯视图或手绘地图，在 UI 上显示玩家位置。

阶段 3：炼金术核心系统
技术选型与关键模块
代价系统：技能 Resource 中定义 cost_type 和 cost_value，释放时检查资源并扣除，根据代价动态调整技能参数（如伤害倍率）。

炼成阵绘制：使用自定义 Shader 在角色脚下绘制动态炼成阵，根据基阵和元素改变纹理和颜色。基阵类型决定技能行为（投射、范围、召唤等）。

技能自定义：玩家在 UI 中选择已解锁的“基阵”和“元素”组合，生成新的 SkillData Resource，保存到技能栏。

合成系统：配方表使用 JSON 或自定义 Resource，检查背包材料，扣除后生成物品。

背包：使用 Array[ItemStack] 结构，UI 使用 GridContainer 显示，支持堆叠、使用、丢弃。

阶段 6：多人联机（可选）

网络插值：对于非本地玩家，使用 Tween 或插值函数平滑移动。
