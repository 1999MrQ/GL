# GL — 《等价之理：哲学家的旷野》游戏项目

一款以"等价交换"为战斗与世界观核心的 3D 开放世界动作 RPG（个人开发，Godot 4.4+，PC 单机买断）。

## 文档结构

| 文件 | 说明 |
|------|------|
| `审核报告.md` | 对原始记录（记录.txt）的策划案与技术方案审核报告，含 V2.0 复审记录 |
| `策划案.md` | 游戏策划案 V2.1：四期开发路线、战斗/元素/等价交换系统、数值框架、排期 |
| `技术方案.md` | Godot 技术方案 V2.1：架构、选型、性能预算、工程基础设施 |
| `记录.txt` | 历史存档：早期 AI 辅助迭代过程记录（**已废弃，不作为开发依据**） |

## 当前状态

文档阶段（策划 + 技术方案已定稿 V2.1）。下一步按技术方案 P0 里程碑（手感原型，全职 6-8 周）启动开发。
